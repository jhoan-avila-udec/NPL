 
## Presentación proyecto final
> **Tarea:** Entrega final con interfaz API de modelo de NLP que permita analizar el asunto y descripción detallada de los tickets registradas en la mesa de servicios (HelpDesk) para determinar cuál es la categoría, subcategoría y área de destino adecuada al problema reportado.

> [!TIP]
> **Solución Actividad:** 
Código ejecutado en Google Colab y exportado en formato .ipynb o en .py. 
Cargue el notebook junto con los archivos `tickets_support_calls.csv`, dado que el dataset proviene de Kaggle. <br>
> **Interfaz:** Acceda desde https://3ccff33e650598586b.gradio.live. Se empleó Gradio para la generación de la interfaz, por lo cual la URL estará disponible solo por tres o cuatro días. Puede compilar el código .ipynb para refrescar la interfaz y generar una nueva URL.
